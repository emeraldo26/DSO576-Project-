# AI Workforce Investment Planner

## Project Area
AI Workforce Investment Planner

## Project Goal
Explore how AI usage, occupation-level tasks, and labor-market data can support workforce decisions.

## Candidate Vision 
A workforce-development agency must decide which occupations should be prioritized for AI-transition training and reskilling support based on observed AI use, task exposure, employment size, wages, and labor-market outlook.

## Core Data Sources
- Anthropic Economic Index
- O*NET Database
- BLS Employment and Wages
- BLS Employment Projections

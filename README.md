# AI Workforce Investment Planner

## Project Area
AI Workforce Investment Planner

## Project Goal
Explore how AI usage, occupation-level tasks, and labor-market data can support workforce decisions.

## Candidate Vision A (TBD)
A company workforce strategy manager in a specific industry must decide which occupations should be prioritized for AI-enabled workflow redesign and employee AI training.

## Candidate Vision B (TBD)
A workforce development director at a public workforce agency must decide which occupations should be prioritized for AI-transition reskilling support.

## Core Data Sources
- Anthropic Economic Index
- OpenAI Signals
- O*NET Database
- BLS Employment and Wages
- BLS Employment Projections
